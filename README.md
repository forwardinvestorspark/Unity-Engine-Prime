## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom C# scripts, Editor extensions, and layout profiles directly into your Unity project's `Assets` and `ProjectSettings` directories. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced editor scripting usage, refer to the `GUIDE.md` file included in the archive.
